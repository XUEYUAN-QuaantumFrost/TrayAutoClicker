# 老式连点器 (Tray Auto Clicker)

轻量 Windows 托盘自动点击工具。没有主界面，常驻系统托盘，右键菜单控制。

## 功能

- 托盘常驻，右键菜单开始/停止
- 全局热键：`Ctrl+Shift+Z` 开始/停止，`Ctrl+Shift+Q` 退出
- 点击间隔随机浮动（默认 0.10 ~ 0.22 秒）
- 点击位置随机抖动（默认 ±4 像素）
- 随机长停顿（默认 3% 概率，额外 0.25 ~ 0.65 秒）
- 可选「跟随鼠标当前位置」或「固定在按下开始的坐标」
- 参数在设置窗口里改，自动存到同目录 `clicker_config.json`
- 运行日志写入 `clicker_log.txt`

## 下载即用（推荐）

不想装 Python 的朋友直接下载编译好的单文件 exe：

1. 到本仓库 **Releases** 页面下载最新版 `连点器.exe`（或仓库根目录同名文件）
2. 双击运行即可，无需安装、无控制台窗口
3. 托盘出现一个像素风图标，右键菜单：
   - **开始 / 停止**：手动触发连点
   - **设置…**：改间隔、抖动、停顿概率
   - **退出**：关闭程序
4. 游戏里按 **`Ctrl+Shift+Z`** 开始/停止，**`Ctrl+Shift+Q`** 退出

> 提示：exe 是单文件，建议放在一个单独文件夹里运行（会自动生成 `clicker_config.json` 配置文件和 `clicker_log.txt` 日志）。

## 直接运行（源码）

需要 Python 3.8 及以上：

```bash
pip install pynput pystray pillow
python 连点器.py
```

启动后托盘出现一个像素风图标，右键即可操作。

## 打包成 exe

```bash
pip install pyinstaller
pyinstaller -F -w -n 连点器 连点器.py
```

生成的 exe 在 `dist/` 目录下，单文件、无控制台窗口。

## 参数说明

| 参数 | 键名 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 最小间隔 | `interval_min` | 0.10 | 两次点击之间最短间隔（秒），下限 0.01 |
| 最大间隔 | `interval_max` | 0.22 | 两次点击之间最长间隔（秒） |
| 位置抖动 | `jitter_px` | 4 | 每次点击相对锚点的随机偏移范围（像素） |
| 停顿概率 | `pause_rate` | 3 | 每次点击后额外长停顿的概率（%） |
| 跟随鼠标 | `follow_mouse` | false | true 则每次点击都取当前鼠标位置为锚点 |

## 热键

| 热键 | 作用 |
| --- | --- |
| `Ctrl+Shift+Z` | 开始 / 停止连点 |
| `Ctrl+Shift+Q` | 退出程序 |

## 适用场景

批量重复点击、界面自动化测试、挂机类场景下的合法重复操作等。
